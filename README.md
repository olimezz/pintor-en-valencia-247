# Pintor en Valencia 24/7 — Web Oficial Mobile-First

Nueva versión web **100 % mobile-first** en español para **[pintorenvalencia247.es](https://pintorenvalencia247.es)** con fotografías originales reales, monograma **PV arcoíris** fiel al icono oficial, tarifas oficiales (`50 m² · 600 €`, `80 m² · 960 €`, `100 m² · 1.200 €`, `120 m² · 1.440 €` + IVA) y calculadora dinámica al instante.

## Enlaces Activos

- **Producción en Vercel:** https://pintor-en-valencia-247.vercel.app
- **Repositorio GitHub:** https://github.com/olimezz/pintor-en-valencia-247

## Estructura

- `index.html` — Secciones *Inicio, Servicios, Galería, Precios, Reseñas, Nosotros y Contacto* con textos directos y concisos.
- `css/styles.css` — Diseño limpio mobile-first con acentos arcoíris inspirados en el logotipo PV.
- `js/app.js` — Comparador Antes/Después con fotos reales, filtros dinámicos de galería con lightbox y calculadora en vivo.
- `assets/logo-pv.svg` y `assets/images/` — Logotipo PV e imágenes reales recuperadas de `pintorenvalencia247.es`.
